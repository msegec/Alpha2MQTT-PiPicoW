v1.28 (fork, msegec/Alpha2MQTT-PiPicoW, 17 October 2026)

First release of the Raspberry Pi Pico W fork. Based on upstream v1.27 (dxoverdy/Alpha2MQTT, June 2024).

Hardware and build
	- Raspberry Pi Pico W target: MP_PICOW in Definitions.h. UART0 on GP0 (TX) and GP1 (RX), transmit
	  enable on GP2, display on GP4 (SDA) and GP5 (SCL). Built with arduino-pico 6.2.0 and the
	  1 MB sketch, 1 MB filesystem flash split. ESP8266 and ESP32 still build.
	- WiFi, MQTT and OTA credentials move to Secrets.h, copied from Secrets.example.h and ignored by
	  git. An empty MQTT_USERNAME connects without credentials.
	- Password protected over the air updates (ArduinoOTA) on the Pico W. scripts/ota-upload builds
	  and uploads over WiFi, reading OTA_PASSWORD from Secrets.h. OTA_HOST_PORT fixes the port the
	  Pico connects back to, for firewalls.

MQTT
	- Alpha2MQTT/state/fast every second: grid power, PV power, battery power, SOC and dispatch
	  start, with seq, ms and read_ms, for a closed loop controller.
	- Alpha2MQTT/state/device every minute on a Pico W: VSYS in millivolts and USB power present.
	- set/charge, set/discharge and set/normal accept an optional seq and echo it with ms.
	- Requests longer than 127 bytes are rejected, never truncated.

Schedules and registers
	- Energy totals report every minute instead of daily. The five minute and daily schedules are
	  empty by default.
	- PV1 to PV6 power (hybrid inverters only) dropped from the ten second schedule.
	- socPercent on set/charge and set/discharge is converted at 0.4 % per bit and rounded up, and the
	  response reports the percent instead of 0. DISPATCH_SOC_MULTIPLIER is gone.

Behaviour
	- MQTT and OTA are serviced between the register reads of a schedule.
	- RS485 replies are polled every millisecond.
	- A five byte Modbus exception reply is reported as a slave error instead of a timeout.

Documentation and tests
	- README: Pico W wiring and build, OTA, the fast state, seq, and a SMILE-B3 finding: the settings
	  block 0x084F to 0x0859 only takes a write while the matching bit of the time period control
	  flag 0x084F is set (bit 1 for 0x0850 to 0x0854, bit 0 for 0x0855 to 0x0859).
	- Home Assistant/alpha2mqtt.yaml: MQTT sensor package for every state topic.
	- Home Assistant/custom_components/alpha2mqtt_controller: a custom integration that regulates the
	  battery against the grid reading in state/fast, driven by a policy entity (release, hold, fixed or
	  regulate with limits and an SOC target). Pure Python core in regulator.py, step log in JSONL.
	  Tests in Home Assistant/tests (python3 -m pytest).
	- tests/firmware/run: host tests for the pure helpers in Dispatch.h.
	- CLAUDE.md: agent guide with the public boundary and live hardware rules.
